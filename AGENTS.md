# Best Practices Coding

- DONOT create duplicate logic
- DONOT create unnecessary complexity
- for the .py files, include #%% so that when I convert it to .ipynb, it is easy to convert into cells
- Code should be readable
- Code should be maintainable
- Code should be reusable
- Code should be reliable
- Code should be consistent
- Code should be documented
- Code should be tested
- Code should be optimized to run time and  memory efficiently on GPU
- Code should be maintained
- Code should be versioned
- when the file path is updated, update all references to it and delete the old path files. 
- 'torch_dtype' is deprecated! Use 'dtype' instead!
